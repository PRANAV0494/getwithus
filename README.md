# Getwithus website

Marketing site, lead pipeline, and admin area for Getwithus, a technology agency.

Built with Next.js 16 (App Router, `cacheComponents`), React 19, Tailwind CSS 4, and TypeScript. The full setup guide, scripts, and environment reference are completed in the final build phase; see `docs/` for decisions recorded so far.

## Quick start

```text
pnpm install
cp .env.example .env.local
pnpm dev
```

Run `pnpm check` (typecheck, lint, knip, unit tests, guard) and `pnpm build` before every commit.
